
# 🌌 AI Universe — Интерактивная 3D карта нейросервисов

Трехмерная визуализация современного рынка нейросетей, представленная в виде вращающейся звёздной вселенной. Каждая нейросеть — это звезда, а созвездия объединяют их по категориям (чат-боты, генерация изображений, код, видео и др.). 

Проект разработан на базе библиотеки **Three.js** с использованием кастомных шейдеров (GLSL) для рендеринга звёзд и сложной математики для распределения объектов в 3D-пространстве.

## 🚀 Ключевые особенности

- **Умное распределение (Физика связей):** Звёзды располагаются не хаотично. Используется алгоритм спирали Фибоначчи для базовых кластеров, а затем применяется система "мостиков" (bridges) — если нейросети из разных категорий имеют общие теги (например, чат-бот и IDE для кода), их звёзды физически притягиваются друг к другу.
- **Кастомные шейдеры:** Звёзды рендерятся через `ShaderMaterial` с использованием аддитивного смешивания (Additive Blending) и шума для эффекта мерцания (twinkle).
- **Интерактивность:** Вращение, зум, выбор звезды мышью (Screen-space picking) с открытием детальной карточки. Поиск по названию и тегам с автодополнением.
- **Фильтрация:** Кликабельная легенда, позволяющая подсвечивать только нужные категории и затемнять остальные.
- **Доступность (a11y):** Семантическая разметка HTML5 и ARIA-атрибуты для скринридеров.

## 🛠 Технологический стек

- **Three.js** (WebGL) — 3D графика и рендеринг
- **GLSL** — Вершинные и фрагментные шейдеры
- **Vanilla JavaScript (ES6 Modules)** — Логика приложения без тяжелых фреймворков
- **HTML5 / CSS3** — Интерфейс, glassmorphism (эффект матового стекла)

## 📂 Структура кода

Весь код находится в одном файле `index.html` для удобства запуска и деплоя. Логически разделен на блоки:

1. **Data (Данные)** — Массив объектов (более 100 нейросетей) и категорий.
2. **Generation (Генерация позиций)** — Алгоритмы Фибоначчи, релаксация (расталкивание звёзд) и вычисление соседей.
3. **Scene (Сцена)** — Инициализация Three.js, камеры, света, стеклянной сферы и туманностей.
4. **Shaders (Шейдеры)** — GLSL код для отрисовки ядер звёзд и их гало (ореолов).
5. **UI / Interaction** — Логика панели информации, поиска, легенды и полёта камеры.

## 💻 Как запустить локально

Так как проект использует ES6 модули, его нужно запускать через локальный сервер (просто открыв файл в браузере, скрипты могут заблокироваться политикой безопасности).

**Способ 1 (Через VS Code):**
1. Установите расширение **Live Server** в Visual Studio Code.
2. Откройте папку с проектом, нажмите правой кнопкой мыши по `index.html` и выберите *"Open with Live Server"*.

**Способ 2 (Через Python):**
1. Откройте терминал в папке с проектом.
2. Выполните команду: `python -m http.server 8000`
3. Откройте в браузере `http://localhost:8000`

## 🌐 Деплой

Проект легко развернуть на GitHub Pages, Netlify или Vercel. Достаточно загрузить файл `index.html` в корень репозитория.
